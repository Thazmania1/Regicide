The enemies

EnemyMovement

Global variables

Name Type Modifiers Description
_calculatedMoves List<Coordinates> protected Stores all valid movement coordinates calculated for the enemy piece.
_lastCoordinates Coordinates protected Tracks the previous coordinates used by certain movement patterns.
_isExtendedPathInterrupted bool protected Indicates whether a multi-tile movement path has been interrupted.
_extendedPathPosition Vector3Int protected Stores the world position used when calculating extended movement paths.
_isBlockedByPiece bool protected Indicates whether a movement path is blocked by another piece.

Methods

Name Parameters Return Type Modifiers Description
Start — void private Initializes references and stores the starting coordinates of the enemy piece.
PlayMove — void protected Selects and executes the move that minimizes distance to the player piece.
ResetPiece — void public override Restores the enemy piece to its pre-match position and re-enables it.

RookMovement

Global variables

Name Type Modifiers Description
_isExtendedPathInterrupted bool protected Indicates whether the rook’s extended movement path has been interrupted.
_extendedPathPosition Vector3Int protected Tracks the current relative position along the extended rook movement path.
_isBlockedByPiece bool protected Marks whether the path is blocked by a player piece, stopping further extension.
_calculatedMoves List<Coordinates> protected Accumulates all valid movement coordinates calculated for the rook.

Methods

Name Parameters Return Type Modifiers Description
CalculatePieceMoves — void public override Calculates all valid rook moves by extending in straight directions across chunks and layers, then executes the chosen move.

BishopMovement

Global variables

Name Type Modifiers Description
_calculatedMoves List<Coordinates> protected Stores all candidate diagonal moves calculated for the bishop.
_lastCoordinates Coordinates protected Tracks the bishop’s previous coordinates to allow alternative path calculations.
_isExtendedPathInterrupted bool protected Indicates whether the extended diagonal path calculation should stop.
_extendedPathPosition Vector3Int protected Represents the current relative position while extending the bishop’s movement path.
_isBlockedByPiece bool protected Marks whether a player piece blocks the path, terminating further extension.

Methods

Name Parameters Return Type Modifiers Description
CalculatePieceMoves — void public override Calculates all valid diagonal bishop moves from the current and, if applicable, the previous position, then executes the optimal move.

KnightMovement

Global variables

Name Type Modifiers Description
_inactiveBlock GameObject private Tracks the inactive block currently occupied by the knight so it can be restored when the knight moves away.

Methods

Name Parameters Return Type Modifiers Description
CalculatePieceMoves — void public override Calculates all valid knight L-shaped moves across available chunks and layers, ignoring block occupancy except for vertical obstruction, then executes the optimal move.
