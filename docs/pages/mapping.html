Mapping system

The map is based on a hierarchic system.

  1. The grid: The manager of the map.
  2. Chunks: The divisions of the grid.
  3. Layers: The Y axis of the chunks.
  4. Blocks: The X and Z axis of the chunks and the grid of the layers.

This allows for a flexible and optimized mapping system.

GridManager

Defines a public constant grid size, both for the chunks and the grids of blocks.

public class GridManager : MonoBehaviour { // Defines the size of the grid public const int GRID_SIZE = 8; ... }

GridManagerEditor

A simple Editor script for GridManager.

Makes the grid's Transform component immutable, and allows to generate chunks through the GridManager's script inspector window.

using UnityEditor; using UnityEngine; [CustomEditor(typeof(GridManager))] public class GridManagerEditor : Editor { public override void OnInspectorGUI() { // UI references EditorGUILayout.BeginVertical("box"); base.OnInspectorGUI(); EditorGUILayout.EndVertical(); GridManager gridManager = target as GridManager; Transform gridManagerTransform = gridManager.transform; serializedObject.Update(); EditorGUILayout.BeginVertical("box"); if(GUILayout.Button("Generate new chunk")) { GameObject newChunk = new GameObject(); Undo.RegisterCreatedObjectUndo(newChunk, "Generated new chunk"); newChunk.transform.parent = gridManagerTransform; newChunk.isStatic = true; newChunk.AddComponent<ChunkBehaviour>().TranslateConcatenatingPosition(); } EditorGUILayout.EndVertical(); serializedObject.ApplyModifiedProperties(); // The grid layout must never be manipulated gridManagerTransform.position = new Vector3(0, 0, 0); gridManagerTransform.rotation = Quaternion.identity; gridManagerTransform.localScale = new Vector3(1, 1, 1); } }
