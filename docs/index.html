Regicide documentation 2.0

Regicide is a school project video game developed in the Unity video game engine.

This documentation assumes that the reader is familiar with any part of Unity's API mentioned here.

Sections colored in green are a new addition to the documentation, and sections colored in yellow were present in the previous version of the documentation, but have been updated. Updated sections will disregard the differences with their previous version.

If you are interested in learning how the video game was planned and developed rather than what the final result does internally, I reccomend checking out its Notion page.
